# Sistema-de-Loja-de-Discos

O Musicaliza Store é um sistema de gerenciamento desenvolvido para uma loja especializada em produtos musicais. O projeto foi elaborado como atividade da disciplina **PEX0130 – Programação Orientada a Objetos**, ministrada pelo professor **Lucas Abrantes Sarmento**, na **Universidade Federal Rural do Semi-Árido (UFERSA)**, Campus Pau dos Ferros.

A proposta do sistema é oferecer uma solução para o controle das operações de uma loja de discos, centralizando o gerenciamento de clientes, produtos, estoque e vendas em uma única aplicação. Além de mídias físicas, como CDs, discos de vinil e fitas, a loja comercializa equipamentos de áudio, acessórios e itens de vestuário relacionados ao universo musical, permitindo que diferentes categorias de produtos sejam administradas de forma integrada.

O sistema possibilita o cadastro e a autenticação de usuários, o gerenciamento de clientes, a manutenção do catálogo de produtos e o acompanhamento das vendas realizadas. Também oferece mecanismos para consulta e atualização de informações, controle de estoque, emissão de comprovantes e visualização do histórico de compras dos clientes.

A modelagem da aplicação foi construída com base nos princípios da Programação Orientada a Objetos, utilizando classes que representam os principais elementos do domínio do problema. Entre as entidades centrais estão Pessoa, responsável pelas informações de acesso ao sistema; Cliente, que representa os consumidores cadastrados; Produto, que reúne os dados dos itens comercializados; Venda, encarregada do registro das transações realizadas; e ItemVenda, responsável pela associação entre produtos e vendas.

Durante o desenvolvimento foram aplicados conceitos fundamentais da disciplina, como encapsulamento, abstração, associações entre classes, utilização de coleções, enumerações e organização modular do código, buscando aproximar o projeto de um cenário real de desenvolvimento de software.
